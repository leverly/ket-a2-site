第 1 周 · 时态地基 夯实基础

语法模块动词时态
核心要点认熟「一般现在 / 现在进行 / 一般过去」的信号词与三单、-ing、不规则过去式拼写；分清 now 和 usually。
刷题验收刷完「动词时态」专项题，建立第一批个人错题本。

第 2 周 · 句型 + 情态动词 夯实基础

语法模块动词形式与基本句型 · 情态动词
核心要点背牢 enjoy -ing / want to do 动词清单；分清 mustn't（禁止）与 don't have to（不必）；写邮件会用 Would you like to…? / Shall we…?
刷题验收完成「动词形式」与「情态动词」两族全部题目 + 重做第 1 周错题。

第 3 周 · 名词冠词 + 代词 + 数量 提分补弱

词汇任务核心高频词 461–683 收官 + 中频词入场
语法模块名词与冠词 · 代词 · 数量词与限定词
核心要点熟记 KET 高频不可数名词（information / advice / homework / money / news）；a/an 按发音判断；much / many / a few / a little 看可数不可数。
刷题验收完成三族专项题，核心高频词达成首轮闭环。

第 4 周 · 形容词副词 + 介词 提分补弱

词汇任务中频主力词（结合 25 个官方话题成组背）
语法模块形容词与副词 · 介词
核心要点牢记不规则比较级 good/better/best、bad/worse/worst；in / on / at 时间地点一次过；整理 listen to / wait for 等搭配。
刷题验收刷完两族专项题，打印本周介词错题纸复习一遍。

第 5 周 · 疑问句 + 连词从句 提分补弱

词汇任务中频词收尾 + 127 条官方短语
语法模块疑问句 · 连词与简单从句
核心要点疑问句坚持「疑问词 + 助动词 + 主语」；杜绝 because + so 连用；if / when 从句不用 will。
刷题验收刷完两族全部题目，重点练习「写作改错」题型。

第 6 周 · 考前全真冲刺 考前冲刺
