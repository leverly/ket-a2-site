∑ 数量词与限定词

much / many / a few / a little：看名词可数不可数，一步判定。

01 some / any / noA1 基础 some 用于肯定句，以及表示提供、请求的疑问句（Would you like some…?）；any 用于否定句和一般疑问句；no… 2 条避坑 · 3 题

some 用于肯定句，以及表示提供、请求的疑问句（Would you like some…?）；any 用于否定句和一般疑问句；no = not any。

  • There are some eggs in the fridge, but there isn't any milk.冰箱里有些鸡蛋，但没有牛奶。
  • Would you like some cake?要来点蛋糕吗？（提供）
  • Have you got any brothers or sisters?你有兄弟姐妹吗？
否定句用 some
I haven't got some money. I haven't got any money.
否定句用 any。
邀请提供时用 any
Would you like any coffee? Would you like some coffee?
表示提供、希望对方说 yes 时用 some。

02 much / many / a lot of / a few / a littleA2 核心 many / a few + 可数复数；much / a little + 不可数；a lot of / lots of 两者都行（… 3 条避坑 · 9 题

many / a few + 可数复数；much / a little + 不可数；a lot of / lots of 两者都行（肯定句更常用）。a few / a little = 一些（肯定）；few / little = 几乎没有（否定）。

03 all / both / each / everyA2+ 衔接 PET both 指两者都；all 指三者及以上都；every / each 后接单数名词，谓语用单数。 2 条避坑 · 2 题

both 指两者都；all 指三者及以上都；every / each 后接单数名词，谓语用单数。

  • Both my parents are teachers.我父母都是老师。
  • All the students passed the test.所有学生都通过了考试。
  • Every room has a TV.每个房间都有电视。
every + 复数
Every students has a locker. Every student has a locker.
every 后接单数可数名词。
两者用 all
I have two cats. All of them are black. I have two cats. Both of them are black.
两者用 both，三者以上用 all。
