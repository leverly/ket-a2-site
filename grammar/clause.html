⌘ 连词与简单从句

写作 Part 6/7 要拿高分，必须用 and / but / so / because / when 把短句连起来。

去练语法真题 →
01 and / but / or / so / becauseA1 基础 and 并列；but 转折；or 选择；so 结果（所以）；because 原因（因为）。because 和 so 不能同时用。 2 条避坑 · 7 题

and 并列；but 转折；or 选择；so 结果（所以）；because 原因（因为）。because 和 so 不能同时用。

  • It was raining, so we stayed at home.下雨了，所以我们待在家里。
  • I like swimming, but I don't like running.我喜欢游泳，但不喜欢跑步。
  • I was late because I missed the bus.我迟到了，因为我没赶上公交车。
because 与 so 连用
Because I was tired, so I went to bed. I was tired, so I went to bed. / Because I was tired, I went to bed.
英语中 because 和 so 只能二选一（中文"因为…所以"的负迁移）。
although 与 but 连用
Although it was cold, but we went out. Although it was cold, we went out.
although 与 but 不能同时出现。

02 时间从句 when / before / after / untilA2 核心 when 当…时；before 在…之前；after 在…之后；until 直到。从句表示将来时用一般现在时。 1 条避坑 · 2 题

when 当…时；before 在…之前；after 在…之后；until 直到。从句表示将来时用一般现在时。

  • When I got home, my mum was cooking.我到家时，妈妈正在做饭。
  • Wash your hands before you eat.吃饭前要洗手。
  • I'll phone you after I finish my homework.我做完作业后给你打电话。
从句中用 will
I'll text you when I will get there. I'll text you when I get there.
时间从句中用一般现在时表示将来。

03 if 条件句（零条件 / 第一条件）A2 核心 零条件：If + 一般现在, 一般现在（普遍事实）。第一条件：If + 一般现在, will + 原形（可能发生的将来）。if 从句… 1 条避坑 · 5 题

零条件：If + 一般现在, 一般现在（普遍事实）。第一条件：If + 一般现在, will + 原形（可能发生的将来）。if 从句不用 will。

类型结构例
零条件If + 现在, 现在If you heat ice, it melts.
第一条件If + 现在, will + VIf it rains tomorrow, we'll stay at home.
祈使If + 现在, 祈使句If you feel ill, go home.
  • If you're free on Saturday, we can go shopping.如果你周六有空，我们可以去购物。
  • If you don't hurry, you'll miss the train.如果不快点，你会错过火车。
if 从句用 will
If it will be sunny, we will go to the beach. If it is sunny, we will go to the beach.
if 从句用一般现在时表示将来，主句才用 will。

04 定语从句 who / which / that / whereA2+ 衔接 PET who 指人；which 指物；that 指人或物；where 指地点。从句放在所修饰的名词后面，用来说明「哪一个」。 2 条避坑 · 5 题

who 指人；which 指物；that 指人或物；where 指地点。从句放在所修饰的名词后面，用来说明「哪一个」。

  • The girl who sits next to me is from Spain.坐在我旁边的女孩来自西班牙。
  • This is the book which I told you about.这就是我跟你说过的那本书。
  • That's the café where we first met.那是我们第一次见面的咖啡馆。
指人用 which
I have a friend which lives in Paris. I have a friend who lives in Paris.
先行词是人，用 who 或 that。
从句里重复代词
The phone that I bought it is broken. The phone that I bought is broken.
that 已经代替了 the phone，从句里不能再用 it。
